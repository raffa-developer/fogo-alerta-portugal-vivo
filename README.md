
# Welcome to your Wildfire Risk Monitoring Project

## Project Download and Setup

### Option 1: Direct Download via Lovable

1. Visit your Lovable project page
2. Look for "Export" or "Download Code" option in project settings

### Option 2: GitHub Clone

```sh
# Clone the repository
git clone <YOUR_GITHUB_REPOSITORY_URL>

# Navigate to project directory
cd wildfire-risk-monitoring

# Install dependencies
npm install

# Start development server
npm run dev
```

### Option 3: Manual Download

1. Use Lovable's code export feature
2. Download the project zip file
3. Extract to your local machine
4. Follow npm installation steps above

## Prerequisites

- Node.js (v18+ recommended)
- npm or yarn
- Git (optional)

## Project Technologies

- React
- TypeScript
- Leaflet Maps
- Tailwind CSS
- Shadcn UI

## Deployment

Deploy easily through Lovable by clicking "Publish" in the project dashboard.
